# Hubery · 朱果

HCI × AI × Games 互动个人网站。访问者可以在小游戏中移动、跳跃、收集金币，浏览五个经历站点；也可以一键阅读简历。所有内容都可以直接访问，无需通关。

## 运行

无需安装依赖。在此文件夹运行：

```sh
python3 -m http.server 4175
```

打开 `http://localhost:4175`。游戏使用方向键或 A / D 移动，空格 / W 跳跃，E 查看详情。手机使用屏幕按钮。简历页支持打印；禁用 JavaScript 时仍可阅读正文。

## 修改内容

- `index.html`：简历正文、项目卡片、照片与站点结构。
- `content.js`：游戏站点简介与经历详情。
- `app.js`：角色移动、跳跃、金币、导航与弹窗。
- `style.css` / `refinements.css`：视觉样式与响应式布局。
- `assets/`：用户提供的照片、简历、作品集、作品图片，以及生成的游戏背景。

修改个人经历时同时更新正文和相关详情。保持论文“已发表”“预印本”“已投稿”状态的准确区分。

## 发布

GitHub Pages 从 `main` 分支根目录发布。将更新推送到该分支后，GitHub 自动重新部署。`.nojekyll` 用于直接发布静态文件。

游戏入口：`https://huberygg.github.io/`

简历入口：`https://huberygg.github.io/#resume`

网站不使用追踪脚本或后端服务。邮箱按钮会打开访问者的邮件应用。项目和视频链接在新标签打开。

## 素材

个人照片与 PDF 来自作者提供的材料。桌游与交互原型图片提取自本科作品集；本科早期项目与毕业设计分别展示。作品及图片权利归原作者所有。像素场景背景使用 AI 生成，游戏角色与交互逻辑为本网站制作。
